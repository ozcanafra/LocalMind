3) Deadlock Avoidance 
Deadlock avoidance, sistemin unsafe state’e geçmesini engeller. 
Yani process kaynak istediğinde sistem şunu kontrol eder: 
Bu kaynağı verirsem sistem güvenli durumda kalır mı? 
Eğer güvenli kalıyorsa kaynak verilir. 
Güvenli kalmıyorsa process bekletilir. 
1) Safe State 
Safe state, sistemdeki tüm process’lerin deadlock olmadan tamamlanabileceği en az bir sıra 
olmasıdır. 
Bu sıraya: 
Safe sequence 
denir. 
Örnek: 
<P1, P3, P2> 
Bu sırayla process’ler tamamlanabiliyorsa sistem safe state’tedir. 
2) Unsafe State 
Unsafe state, deadlock var demek değildir. 
Ama: 
Deadlock oluşma riski vardır. 
Ezber: 
Safe state → deadlock yok 
Unsafe state → deadlock olabilir 
Deadlock state → sistem kilitlenmiş

4) Deadlock Detection 
Deadlock detection, sistem deadlock oluşmasına izin verir ama sonra kontrol eder. 
Bu yaklaşımda sistem periyodik olarak şunu sorar: 
Şu anda deadlock var mı? 
1) Tek Instance Kaynaklarda 
Her kaynak türünden tek örnek varsa: 
Wait-for graph 
kullanılır. 
Wait-for graph’ta: 
P1 → P2 
demek: 
P1, P2’nin tuttuğu kaynağı bekliyor. 
Graph’ta cycle varsa deadlock vardır. 
2) Çok Instance Kaynaklarda 
Her kaynaktan birden fazla varsa detection algoritması kullanılır. 
Banker’s algorithm’e benzer ama amacı safe state bulmak değil, deadlock’taki process’leri 
tespit etmektir.
